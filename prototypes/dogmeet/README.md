# Dogmeet — «Расписание двора»

Изолированный мобильный React-прототип. 38 экранов и нижних панелей, 136 вариантов (38 базовых + 98 дополнительных). Backend не используется. Ничего не публикуется.

## Запуск

Из корня существующего проекта:

```sh
node prototypes/dogmeet/start.mjs
```

- Прототип: http://127.0.0.1:4178/#nearby
- Начало пользовательского сценария: http://127.0.0.1:4178/#welcome
- Галерея: http://127.0.0.1:4178/gallery.html
- Админка: http://127.0.0.1:4178/#admin-login — `demo` / `dogmeet`.

Используются уже установленные React, Vite, lucide-react и Playwright. `package.json`, зависимости, lock-файлы, production-маршруты и API не меняются. Сервер слушает только loopback, не публикуется в сети.

## Как смотреть

На широком экране отображается только мобильный контейнер; служебный инспектор находится снаружи. На узком экране инспектор расположен после прототипа. Там можно выбрать любой экран, состояние и сбросить моковые данные. Галерея открывает каждый вариант напрямую, например `/#new-pet?state=validation`. Параметр `?capture=1` скрывает инспектор для PNG.

Данные живут в памяти текущего просмотра и сбрасываются при полной перезагрузке. Версия отозванной ссылки хранится отдельно в `sessionStorage` под ключом `dogmeet.prototype.link-version`, чтобы отзыв работал и при открытии ссылки в той же вкладке. Настоящие сессии, база, геолокация, уведомления и отправка сообщений не используются. Копирование в буфер выполняется только по кнопке. Фото читаются локально и никуда не отправляются.

## Проверить анимации

1. Откройте `http://127.0.0.1:4178/?nav=floating#nearby`. Переключите «Рядом → Питомцы → Мои планы»: контент движется на 20 px, подложка меню следует за вкладкой.
2. В «Питомцы» откройте Боню и вернитесь кнопкой «Назад»: фото связывает список и паспорт. Откройте «Поделиться питомцем», закройте панель крестиком; Escape закрывает её мгновенно.
3. Добавьте питомца: обязательные поля переключают Plus на Check, отправка показывает loading/success. В админском экране «Уведомления» переключатель показывает toast.
4. Включите системное сокращение движения: остаются только короткие fades/color. На desktop макет сохраняет мобильную геометрию, инспектор находится снаружи.

Точная проверка motion (preview должен работать): `node prototypes/dogmeet/check-motion.mjs`. Проверяет native snapshots, направления, browser Back/Forward, shared-photo, прерывание закрытия, фокус, форму и fallback без View Transitions. CSS/WAAPI не требуют новых зависимостей. PNG в галерее — статические снимки; анимации доступны в живом прототипе.

## Артефакты

- `gallery.html` — обзор с фильтром и прямыми ссылками на 136 макетов/PNG.
- `png/` — отдельный PNG каждого базового экрана и значимого дополнительного состояния; длинные экраны сняты полностью при ширине 390 px.
- `COVERAGE.md` и `catalog.mjs` — полная таблица соответствия исходных и новых экранов.
- `RESEARCH.md`, `research/` — просмотренные референсы, три концепции и выбранная система.
- `QA.md`, `check-results.json` — результаты проверок и ограничения.

## Проверки

```sh
node prototypes/dogmeet/start.mjs --build
node_modules/.bin/eslint --config prototypes/dogmeet/eslint.config.mjs prototypes/dogmeet/app.jsx prototypes/dogmeet/catalog.mjs prototypes/dogmeet/check.mjs prototypes/dogmeet/start.mjs
node prototypes/dogmeet/check.mjs --capture
```

Для последней команды сервер должен работать. Используется установленный Chromium Playwright. Проверка выполняет пользовательские сценарии и все 136 вариантов на 360, 390, 430 px; сохраняет PNG на 390 px и JSON-отчёт. Для длинного снимка viewport расширяется по высоте документа: навигация остаётся внизу изображения, а не закрывает середину длинной страницы. Функциональная проверка выполняется на обычной высоте 844 px, формы дополнительно — на высоте 430 px.

## Изоляция

Все новые исходники и документы находятся только в `prototypes/dogmeet`. Существующие пользовательские изменения не редактировались. Импорты серверной бизнес-логики и API отсутствуют. Иконки — установленный lucide-react. Шрифт Manrope хранится локально с лицензией SIL OFL. Изображения взяты из существующего `public/`; происхождение перечислено в `assets/PROVENANCE.md`.
