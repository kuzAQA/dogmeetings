# Источники ресурсов

- `manrope-regular.ttf`, `manrope-bold.ttf`: Manrope, Google Fonts, https://fonts.google.com/specimen/Manrope. CSS получен из https://fonts.googleapis.com/css2?family=Manrope:wght@400;500;600;700;800&display=swap 14.09.2026; локально сохранены начертания 400 и 700. Лицензия `OFL.txt` получена из https://github.com/google/fonts/blob/main/ofl/manrope/OFL.txt.
- `/dog-bonya.webp`, `/dog-luna.webp`, `/dog-richie.webp`, `/dog-placeholder.webp`, `/walk-hero.webp`: существующие изображения проекта в `public/`, просмотрены и переиспользованы без модификации. Первоначальные авторство/лицензия в проекте не указаны; внешняя публикация прототипа не выполнялась.
- `../research/dogmeet-*.png`: собственные снимки реально просмотренных публичных страниц для внутреннего исследования. Не используются в продуктовом интерфейсе.
- `../png/*.png`: собственные снимки реализованного локального прототипа через Playwright. Генеративные изображения не применялись.
