# Уведомления о сообщениях

«Мой район и настройки» → «Уведомления» открывает выбор Push и Telegram.
Каждый способ подключается и отключается через диалог.

Для Telegram нужно открыть бота кнопкой в диалоге, подтвердить подписку на прогулки ЖК,
вернуться на сайт и нажать «Подключить Telegram». Это связывает сессию сайта с Telegram;
старым подписчикам также нужно один раз пройти привязку. Отключение уведомлений
о сообщениях сохраняет подписку на прогулки. Отмена всех подписок на прогулки прекращает
доставку сообщений; при возобновлении подписки сохранённая настройка снова действует.

Перед использованием нужна миграция `drizzle/0048_telegram_chat_settings.sql`
через существующий механизм миграций. Секреты и переменные окружения не меняются.

Проверки:

```sh
node --test lib/telegram-chat.test.mjs lib/telegram-subscription-flow.test.mjs
pnpm exec playwright test e2e/notifications.spec.ts e2e/push-unread.spec.ts --project=mobile
```

Для проверки SQL и миграции укажите `CHAT_TEST_DATABASE_URL` тестовой PostgreSQL-базы
в первой команде. Тест создаёт отдельную временную схему и удаляет её после проверки.
Без этой переменной пропускается только PostgreSQL-сценарий.

В Telegram передаются только факт нового сообщения и имя отправителя. Повтор запроса
с тем же идентификатором сообщения не отправляет повторное уведомление. Сбой Telegram
не отменяет сохранённое сообщение; отдельной очереди повторной доставки здесь нет.
